# Python Server SDK

Python now ships a reusable reference SDK in [secure_http_server_sdk.py](./secure_http_server_sdk.py).

It covers the same core pieces as the Go and Node server SDKs:

- manifest-driven config
- gate verification
- `/handshake` processing
- in-memory session management
- secure request decrypt / response encrypt helpers
- browser login/bootstrap payload builders

Recommended framework mappings:

- FastAPI / Starlette: ASGI middleware for gate verification plus request/response wrapping.
- Flask: `before_request` gate/session resolution and response post-processing.
- Django: middleware around secure routes.

## Minimal usage

```python
from sdks.server.python import SecureHttpServerSDK

sdk = SecureHttpServerSDK(
    {
        "handshakePath": "/handshake",
        "requireDevice": True,
        "requireUser": True,
        "gateSecrets": [{"id": "2026-Q1", "secret": b"gate-secret-1"}],
        "gateSecretStrings": {"2026-Q1": "base64:Z2F0ZS1zZWNyZXQtMQ=="},
        "deviceSecrets": {"device-1": b"device-secret-1"},
        "deviceSecretStrings": {"device-1": "base64:ZGV2aWNlLXNlY3JldC0x"},
        "capabilities": [
            {
                "token": "cap-root",
                "routes": [
                    {"path": "/handshake", "methods": ["POST"]},
                    {"path": "/api/echo", "methods": ["POST"]},
                ],
            }
        ],
    },
    user_authenticator=lambda token: {"id": "user-1"} if token == "user-token-1" else None,
)
```

Use `verify_gate(...)`, `handle_handshake(...)`, `decrypt_request(...)`, and `encrypt_response(...)` inside your framework middleware or route wrapper.

## Contract requirements

1. Validate gate headers before route dispatch.
2. Implement `POST /handshake` with the canonical JSON fields.
3. Store derived session keys and metadata.
4. Decrypt request envelopes before your application handler runs.
5. Encrypt successful handler responses back into the canonical message envelope.
6. Reuse the browser login/bootstrap contract for browser clients.

Use the manifest generated by Go as the source of truth for header names, route capabilities, cookie names, CSRF names, and bootstrap paths.
