# Go Server SDK

Go is fully supported in-repo.

Use:

- `sdks/server/go/stdlib` for `net/http`, `chi`, and most Go HTTP stacks.
- `sdks/server/go/fiber/server` for Fiber.
- `sdks/server/go/manifest` to export the portable manifest consumed by non-Go SDKs.

For a complete walkthrough, see [docs/server-sdk.md](/Users/sujit/Sites/secure-http/docs/server-sdk.md:1).
